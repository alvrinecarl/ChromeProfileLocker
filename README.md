# Chrome Profile Locker

A password-protected launcher for Google Chrome profiles.

## Features

- Automatically detects Chrome profiles.
- Set individual passwords for Chrome profiles.
- Settings protected by a personal PIN.
- Change your Settings PIN.
- Launch your selected Chrome profile after authentication.

## Installation

1. Download `ChromeProfileLocker.zip` from the [Releases](../../releases) page.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Find `ChromeProfileLocker.exe`.
5. Right-click it and select **Show more options → Send to → Desktop (create shortcut)**.
6. Rename the desktop shortcut to **Chrome Profile Locker**.

**Important:** Do not move the actual EXE out of its extracted folder. Create a shortcut instead.

## Recommended Desktop Setup

To make Chrome Profile Locker your main way of opening Chrome:

1. Locate your existing Google Chrome desktop shortcut.
2. Right-click it and select **Delete**.
3. Keep the Chrome Profile Locker shortcut on your desktop.
4. Open Chrome using Chrome Profile Locker.

**Do not uninstall Google Chrome or delete its installation files.** The launcher needs Chrome installed to work.

## First-Time Setup

1. Open Chrome Profile Locker.
2. Create your own Settings PIN.
3. Open Settings.
4. Select a Chrome profile.
5. Set a password for that profile.
6. Save your settings.

## Changing Your Settings PIN

1. Open Settings.
2. Enter your current PIN.
3. Click **Change Settings PIN**.
4. Enter your current PIN.
5. Enter and confirm your new PIN.

## Requirements

- Windows
- Google Chrome installed
- Required Microsoft .NET Framework runtime for the application

## Security Notice

Chrome Profile Locker is a password-protected launcher. It controls access through the launcher but does not provide full operating-system-level protection.
